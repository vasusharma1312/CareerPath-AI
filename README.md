# CareerPath AI – Machine Learning Based Career Recommendation System

## 1. Project Overview
CareerPath AI is a machine learning based project that helps students find suitable career options based on their skills, interests and abilities.

The project uses Python and Machine Learning algorithms to analyse student information and recommend possible career paths.

## 2. Objectives
- To understand the fundamentals of Machine Learning.
- To analyse student skills and interests.
- To recommend suitable career options.
- To display results through an interactive dashboard.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn
- Joblib

## 4. Project Structure
- app.py – Main Streamlit application
- generate_dataset.py – Dataset generation
- train_model.py – Model training
- data/ – Dataset storage
- model/ – Trained model and visualisations
- pages/ – Additional application pages
- assets/ – Project assets
- screenshots/ – Application screenshots

## 5. Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## 6. How to Run

Start the application using:

```bash
streamlit run app.py
```

The application will open in your web browser.

## 7. Conclusion

CareerPath AI demonstrates how Machine Learning can be used to support students in exploring suitable career opportunities. It combines data analysis, model training and an interactive web dashboard in one project.
